# Prompt 与收藏内容库设计

## 目标

让 Prompt 与收藏均可新增、编辑、删除，并让最近复制内容可以一键收藏。所有数据只保存于本机。

## 数据模型

- 新增独立的可管理内容库，保存 Prompt 与收藏项目。
- 首次运行时把当前内置 Prompt 和收藏示例写入内容库；之后它们与用户新建内容没有权限差异，均可编辑或删除。
- 剪贴历史继续独立保存。清空历史不会删除 Prompt 或收藏。
- 最近复制一键收藏时，按内容去重；重复收藏不会新增第二条。

## 界面与操作

- Prompt 分类顶部提供“＋ 新建 Prompt”。
- 新建表单包含标题与内容，并展示中文示例：标题“例如：实现一个新功能”，内容“请帮我完成……”。
- 表单说明可使用 `{{功能描述}}` 与 `{{技术约束}}` 变量。
- Prompt 和收藏卡片提供“更多”菜单，包含编辑与删除。
- 删除必须二次确认，确认后永久删除，不提供撤销。
- 最近复制卡片提供星标按钮；收藏成功后显示已收藏状态。

## 数据流

1. 侧栏打开时，内容库与历史一同加载。
2. 新建、编辑、删除或收藏操作立即更新内存状态并编码保存到 `UserDefaults`。
3. 列表按分类读取内容库；最近复制区仍优先展示最新剪贴内容。
4. 复制、粘贴与快捷键行为保持不变。

## 验收标准

- Prompt 与收藏都可以新增、编辑、删除并重启后保留。
- 内置模板可以编辑和删除。
- 最近复制可以一键收藏且不会重复。
- 删除需确认，确认后不再出现。
- 不影响剪贴记录、搜索、键盘选择与粘贴流程。
